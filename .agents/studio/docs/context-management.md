# Context and recovery

Read the bounded active checkpoint and verify its branch/story against the current worktree. Load only relevant workflow references, source, ADRs and evidence. Prefer deterministic facts from shared helpers over reading the entire studio manual.

Helpers emit observations, not game-quality verdicts. Check denominators, missing inputs, timeouts and actual results. A document/template existing is not completion. Record real commands, changed inputs and native agent identities; never manufacture approvals or measurements.

The coordinator writes checkpoints at authorized developmental phase boundaries through session-state.sh. Concurrent stale updates must be rejected rather than overwrite newer progress. features.session_state=off is honored. Read-only/plan/review operations do not rewrite protected project state. Native hook logging is isolated, bounded and not QA evidence.
