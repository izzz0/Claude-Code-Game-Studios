# Team execution

Nine ccgs-team-* skills coordinate the native role catalog. No experimental source-host environment variable or model API is required. Team skills run through the current Codex session's native subagent tools; shell helpers do not start models.

team.size individual selects the essential role(s), small adds the necessary cross-discipline collaborators, and studio selects the full task-relevant lineup. Even studio does not require all 49 profiles on every task. Queue work within host concurrency. See coordination-rules.md for ownership, independent review, receipts and recovery.

A stored team manifest records work but does not prove a native agent ran. Keep actual host run IDs and substantive returned results. Native execution tests and protocol fixtures must remain distinguishable in validation reports.
