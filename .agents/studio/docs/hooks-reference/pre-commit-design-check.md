# Commit design checks

The preserved commit helper inspects the design bytes the commit would record. GDD section observations follow the resolved workflow: minimal has no mandatory system GDD, standard requires its documented five sections, and full requires eight.

Missing sections are observations to assess against the actual design/story contract; they are not a substitute for design review. Use ccgs-design-review and ccgs-gate-check for applicable independent gates. The hook never rewrites a design or advances a stage.
