# Commit code checks

The native PreToolUse adapter invokes the preserved commit-snapshot helper for canonical shell commit commands. It distinguishes staged bytes, working bytes taken by commit -a, explicit path-limited commits and a preceding git add.

Malformed engine asset data JSON blocks the pending commit. Code markers and gameplay-value observations use the configured engine code root. These observations are not proof of compilation, engine tests, performance or a clean code review.

Additional language-specific formatting/linting remains an explicit project check using actual configured tools. No placeholder command produces PASS.
