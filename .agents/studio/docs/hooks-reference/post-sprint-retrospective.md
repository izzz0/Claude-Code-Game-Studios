# Retrospective after a sprint

A completed sprint may route the coordinator to ccgs-retrospective. This is an explicit skill, not a hook that recursively launches Codex or a model.

Use the sprint's actual story results, blockers, defects and evidence. Produce recommendations within the accepted task; do not invent velocity or silently change scope. Review/planning remains read-only. Future scheduled follow-up requires the user's corresponding request.
