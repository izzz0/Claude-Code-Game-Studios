# Velocity Courier

## Player goal & fail state

Move the courier with A/D, stay inside the wall boundaries, collect all three
targets, and restart the run after the collection sequence. The run fails when
the courier crosses a wall boundary or a target is counted twice.

## MVP

- Keyboard movement with wall boundaries.
- Collect three targets and restart the run; this feature depends on movement.

## Build order

1. Movement and wall boundaries.
2. Three-target collection and restart, after movement is complete.
