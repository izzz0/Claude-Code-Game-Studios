## Reproduction Steps
**Preconditions**: Use a build containing the current `src/game.gd` collection guard. Start the one-screen courier scene with all three targets available. These scene steps are based on the author's description and have not been played during this report.

1. Reach Target Alpha at index 0 and attempt collection.
2. Reach Target Beta at index 1 and attempt collection.
3. Reach Target Gamma, the third target at index 2, and trigger collection through `collect_target(2)`.
4. Observe the collection return value and whether the third parcel is recorded as delivered; repeat the third collection attempt.

**Expected Result**: The third target is accepted and recorded as delivered, satisfying STORY-001 AC-3.
**Actual Result**: Collection is rejected every time; the guard returns `false` for index 2 and the third target is not recorded as delivered (reported scene outcome).

## Technical Context
- **Likely affected files**: `src/game.gd`, especially lines 3 and 5–8.
- **Related systems**: Delivery progress recording; its implementation is not present in the inspected script.
- **Possible root cause**: The three-element `targets` array includes Target Gamma at index 2, but `collect_target` uses `if target_index >= 2: return false`. For input 2 the condition is true, so execution cannot reach `return true`. This excludes a valid target through an incorrect upper bound.
- **Impact**: Blocks completion of all three parcels and STORY-001 AC-3.

## Evidence
- **Source inspection**: Read `src/game.gd` and searched for `collect_target`, `target_index`, and `Target Gamma`. The guard and target array directly support the index-2 rejection.

```gdscript
var targets := ["Target Alpha", "Target Beta", "Target Gamma"]

func collect_target(target_index: int) -> bool:
    if target_index >= 2:
        return false # BUG: third target is index 2
    return true
```
