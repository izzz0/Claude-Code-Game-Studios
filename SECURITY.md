# Security

Do not commit credentials, personal configuration or proprietary game assets.
Review project commands before execution; the framework runs the game's own
configured commands with the host's permissions.

This fork installs no shell permission system or automatic security hooks.
Codex environment permissions and the user's task authorization remain in force.
For a vulnerability, use GitHub's private reporting mechanism if enabled, or
contact the repository owner privately. Do not post secrets in public reports.
